# 新师训练营｜教师端系统工作区

## 当前目标

本工作区用于建设教师端前后端一体系统，覆盖公司邮箱注册登录、My TIDE、成长路径、系统内任务、素材存储和数据回流。

世文系统负责业务数据、积分和业务结果；本系统面向老师展示并执行连续编号的 `G01–G09` 共 9 个固定成长任务。`G04` 是合并后的 `Lesson Preparation&Device Network Check`，重排前旧 `G05` 以隐藏技术编码 `G00` 只读保留，不进入当前任务列表。两端共用同一个 PostgreSQL，直接共享 `task_templates` 和 `task_assignments`，教师端不写积分表。个性化任务以世文任务触发中心创建的真实 assignment 为准；TIDE 只读其状态与截止时间并将新任务／到期提醒写入 `tide.system_notifications`，不写 `public.notifications`。

## 当前默认口径

- 老师使用公司邮箱和密码注册，注册后必须完成邮箱验证。
- 登录后默认进入 My TIDE，今日任务合并到 My TIDE，不再单独设置首页。
- 除 `G01` 的 Self-intro／TESOL 在外部既有流程完成外，视频、文档、小测、清单、上传和设备环境检查原则上在系统内完成；`G05–G09` 及其他视频类任务全部在本系统内观看和完成，附加小测、清单和重试规则由任务级 PRD 配置。
- 视频固定 1 倍速，第一次完整看完前不能拖动进度条，未看完不计入任务完成进度。
- 文档内容内化为系统原生页面，不使用 PDF、Word 或外部预览器展示。
- 初始版题目、答案、任务流程和完成规则由项目团队在本系统配置。
- 设备环境检查使用标准清单和任务明确要求的照片留证；`G05–G09` 与其他视频类任务均不再依赖外部培训完成标签。
- 教师只在任务明确要求时上传照片或截图证据；课程视频、原生图文和示例图片由项目组配置并迁移到 OSS／CDN，题库按版本导入教师端数据库，前端不保存题目或标准答案。
- 共享库的当前固定任务为 `G01–G09`；教师端按这 9 个任务开放阶段，世文的积分进程仍以共享记录幂等结分。隐藏的 `G00` 只作历史兼容，不生成入口。
- 视频心跳、观看区间、答案、清单明细、图片、文件和内部判定依据只保存在教师端自有业务表，不写入共享 `task_assignments`。
- 不再建设任务 HTTP 下发／回传接口，也不保留第二套跨系统任务副本。
- `public.notifications` 只作为世文业务文字提醒读取，不承担个性化任务分配或到期提醒；个性化任务实际截止时间读取 assignment 的 `due_at`，时区证据读取三个 `timezone_*` 字段。
- 教师累计积分、五维、出营和金牌结果读取 `teacher_scorecard_current`；逐课三维和正向加分来源读取 `teacher_lesson_score_current`。教师端不从原始表或评分配置自行计算，也不使用本地积分兜底。
- 当前阶段暂用 Day 1-7、Day 8-14、Day 15-30。
- 教师端不直接展示投诉判责、拉黑、红黄风险、淘汰等运营内部信息。

## 仍待业务确认

- 30 天起算节点和正式阶段名称。
- `G01–G09` 的本地任务级 PRD、素材、开放顺序和可信校验方式；隐藏 `G00` 的资料仅作历史兼容。
- 个性化改善任务剩余模板、内容版本和真实触发样例。
- 公司邮箱域名、邮件发送服务和验证链接有效期。
- 素材导入、更新、版本和下架方式。
- 各具体任务的内容、题目、步骤和完成规则。
- 拍摄图片和上传文件的保留、删除和授权规则。
- 个性化任务固定英文提醒文案的业务审定，以及各任务的培训素材、实际截止值、完成标准和帮助入口。
- Toki 官方素材及英文说话风格。
