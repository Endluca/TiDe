# 新师训练营｜教师端系统工作区

## 当前目标

本工作区用于建设教师端前后端一体系统，覆盖公司邮箱注册登录、My TIDE、成长路径、系统内任务、素材存储和数据回流。

世文系统负责业务数据、积分和业务结果；本系统面向老师展示并执行连续编号的 `G01–G09` 共 9 个固定成长任务。`G04` 是 `Lesson Preparation`，只保留授课环境拍照 AI 检查和课件准备确认；重排前旧 `G05` 以隐藏技术编码 `G00` 只读保留，不进入当前任务列表。两端共用同一个 PostgreSQL，直接共享 `task_templates` 和 `task_assignments`，教师端不写积分表。个性化任务以世文任务触发中心创建的真实 assignment 为准；TIDE 只读其状态与截止时间并将新任务／到期提醒写入 `tide.system_notifications`，不写 `public.notifications`。

## 当前默认口径

- 当前为 `HYBRID`：保留公司邮箱注册、验证、密码登录和找回密码，同时支持从 CRM SSO 免登录进入。正式稳定后可通过配置切到 `CRM_SSO_ONLY`，再另行清理旧入口。
- 登录后默认进入 My TIDE，今日任务合并到 My TIDE，不再单独设置首页。
- `G01`、`G05–G08` 的考试／培训只在任务页 iframe 内使用阔知完成，不提供阔知外跳按钮，也不运行 TIDE 本地播放器或答题完成链路；`G09` 遵循同一边界，但阔知课程、视频和考试任务 ID 发布前保持内容待配置。G02 使用 TIDE 原生版本化 `Overseas NT Policies` 文档，中文界面显示中文译文，读到当前发布版本末尾后由后端原子完成任务。
- 阔知负责视频播放、续播、完播、测试作答和原始结果；TIDE 后端查询并以映射任务的 `percent=100` 判定，不由前端复制规则。
- 文档内容内化为系统原生页面，不使用 PDF、Word 或外部预览器展示。
- 初始版题目、答案、任务流程和完成规则由项目团队在本系统配置。
- 设备环境检查使用标准清单和任务明确要求的照片留证；视频／测试类任务只使用阔知学习结果作为正式完成证据。
- 教师只在任务明确要求时上传照片或截图证据；阔知类任务的视频和题目不迁移到 TIDE。考试是否完成只依据阔知返回的 `percent=100`，`score` 仅作为展示与审计证据。
- 共享库的当前固定任务为 `G01–G09`；教师端按这 9 个任务开放阶段，世文的积分进程仍以共享记录幂等结分。隐藏的 `G00` 只作历史兼容，不生成入口。
- 阔知查询快照、图片、文件和内部判定依据只保存在教师端自有业务表，不写入共享 `task_assignments`；阔知视频心跳和答案不在 TIDE 保存。
- 不再建设任务 HTTP 下发／回传接口，也不保留第二套跨系统任务副本。
- `public.notifications` 只作为世文业务文字提醒读取，不承担个性化任务分配或到期提醒；个性化任务实际截止时间读取 assignment 的 `due_at`，时区证据读取三个 `timezone_*` 字段。
- `P-FB-NEGATIVE` 中已确认的授课环境问题使用与 G04 相同四项标准的拍照 AI 检测；只接受任务触发中心写入的稳定变体，或上线前两枚精确历史标签兼容，不对其他差评标签模糊匹配。个性化照片每次独立检测，本次 PASS 即完成；不保留照片或审核明细，不复用历史 PASS。G04 原有行为不变。
- 教师累计积分、五维、出营和金牌结果读取 `teacher_scorecard_current`；逐课三维和正向加分来源读取 `teacher_lesson_score_current`。教师端不从原始表或评分配置自行计算，也不使用本地积分兜底。
- 当前阶段暂用 Day 1-7、Day 8-14、Day 15-30。
- 教师端不直接展示投诉判责、拉黑、红黄风险、淘汰等运营内部信息。

## 仍待业务确认

- 30 天起算节点和正式阶段名称。
- `G01–G09` 的本地任务级 PRD、素材、开放顺序和可信校验方式；隐藏 `G00` 的资料仅作历史兼容。
- 除已确认授课环境拍照变体外，个性化改善任务剩余模板、内容版本和真实触发样例。
- 公司邮箱域名、邮件发送服务和验证链接有效期。
- 素材导入、更新、版本和下架方式。
- 各具体任务的内容、题目、步骤和完成规则。
- 拍摄图片和上传文件的保留、删除和授权规则。
- 个性化任务固定英文提醒文案的业务审定，以及各任务的培训素材、实际截止值、完成标准和帮助入口。
- Toki 官方素材及英文说话风格。
