📌 本版关键变更（会议决策 + 07-20 机制修正）

  • 金牌机制（07-20 修正）：内部计分逻辑完全不变（无封顶累加）；只是给外教看的数字封顶在 200。金牌 = 内部原始分 ≥ 200（此时外教看到顶格 200）。上一版多加的"内部锚定 top10% 再缩放映射"已删除——那是我的过度设计，会议本意就是"显示封顶 200"，不是缩放。
  • 不扣分、用红线替代：迟到/早退/真实缺席作为金牌排除项（红线），不在计分中做减法，与会议一致。
  • 金牌硬门槛（前置条件）：基础分=40 全拿 + 完课≥10 + 用户反馈分≥20 + 四害红线（迟到≤1 / 早退=0 / 真实缺席=0）。金牌不只是分数达标，还要"均衡 + 纪律干净"。
  • 升档映射记录：出营 +1 档、金牌 +2 档（钱/职级侧，见第六节，不进打分模型）。
  • 标准固定、不随老板百分比摇摆：金牌 = 绝对线 200（对外显示封顶），是固定门槛；老板要更多优秀 = "多拉人达到 200 分"，而非降标。
  • 基础分结构细化（07-20）：基础分拆为三块——成长任务（必修）30 + 供给任务（选修）10 = 40 固定；个性化任务（触发制，不加分）仅作行为引导，不计入积分。评分逻辑不变。

一、整体结构（不变）

基础分（固定 40，不随本方案变动）

· 成长任务（必修） 维度5：满分 30 —— 新师必完成的培训/成长动作，出营底线

· 供给任务（选修） 维度4：满分 10 —— 自愿完成的供给动作，拿满 40 才达金牌基础门槛

· 个性化任务（触发制，不加分）：由特定事件触发的引导任务，不计入积分，仅作行为引导

基础分 = 成长任务(必修) 30 + 供给任务(选修) 10 = 40 分，作为底线治理门槛；个性化任务触发制、0 分。

课程分（本方案设计，累加无封顶）

· 维度1 用户反馈：事件型

· 维度2 可靠性：行为型

· 维度3 课堂质量：无质量问题 +2/节 × 80% 达成（模拟）

30 天新兵营内所有课程得分累加，不设任何分数封顶。

原始总积分 = 40（基础分 = 成长任务必修30 + 供给任务选修10） + 课程分（维度1 + 维度2 + 维度3，逐项累加，零封顶）
个性化任务为触发制、不加分，仅作行为引导，不进入上式。

二、课程分计分规则（无封顶版）

本版删去的"长期持续/复杂"指标： 稳定性大奖（连续7天+5 / 连续10天+8 / 30天稳定+10）、 无投诉+10（需30天全程无有效投诉）。 这些指标需跨整个营期追踪连续表现，运营成本高且解释复杂，故移除。 保留的全部为按次 / 按节即可计分的干净指标。
本版相对封顶版的两处变更： ① 取消全部分数封顶——准时完课、Peak 完课、维度3 课堂质量均按节无限累加，高课量老师的可靠性/课堂质量分不再受限； ② Peak 完课由 +2/节 降为 +1/节。 两项叠加后，分数整体大幅上浮（见第四节），且内部权重结构改变，请重点关注下方风险提示。

三、出营 / 金牌分数线 + 对外显示封顶（会议决策核心）

机制（07-20 修正，按会议本意）： 内部计分逻辑完全不变——原始分继续无封顶累加，老师每多得一节好课、每条好评，内部分数如实上涨。差别只在给外教展示的数字封顶在 200：原始分 150 就显示 150，原始分 660 也只显示 200。对应王东"考卷 150 分封顶"的思路——分数可累加，但对外呈现有顶。
出营 = 原始分 ≥ 100（显示 ≥100）；金牌 = 原始分 ≥ 200（显示顶格 200）。没有"内部缩放映射"，没有"锚定 top10%"，就一层简单的显示封顶。
对外显示分 = min(原始分, 200)
  原始分 < 100：显示原始分（未出营，0–99）
  100 ≤ 原始分 < 200：显示原始分（出营区间，100–199）
  原始分 ≥ 200：显示 200（金牌封顶）

五、和谐性与风险

和谐性变化：基础分（40）仍以"硬门槛+必修"锁底线治理权；课程分作分层排序主驱动。但无封顶后课程分被课量主导——可靠(41%)+课堂(24%)=65% 与课量直接挂钩，反馈(36%)降至第二位。

风险 0（反馈最高优先原则被打破）：基石 doc 明确"用户反馈"为最高优先级维度，封顶版中反馈占 67% 居首；无封顶后可靠性以 41% 反超反馈(36%)。高课量但反馈平平的老师会靠"刷课"胜出，与 doc 标题"100%用户价值出发"相悖。若坚持无封顶，建议把反馈权重进一步上调（如好评+8/收藏+8/复约+12）以夺回主导权，否则应恢复封顶。

风险 1（金牌率高于会议预期）：金牌=原始分≥200 是会议拍板的绝对线、对外显示封顶 200。回测通过率 36.6%（390 人），高于会议口头"≈10% 尖子"预期。这是"无封顶 + 维度3=1.6×完课"下尺度被拉大的自然结果。金牌硬门槛（反馈分≥20 + 四害红线）已用于拦截纯堆课型老师；若要更尖，应在"拉人达标"上发力，标准本身不随老板百分比摇摆。

风险 2（维度3为模拟值）：4 月数据无课堂质量字段，维度3 按"每节+2、80%达成"模拟（无封顶）。真实达成率未知，实际总分可能更高；蜂巢/TQ 真实数据接入后须替换重算，届时按新分布微调分数线。

风险 3（基础分假设）：回测中基础分按满分 40 假设；真实基础分由培训系统给，若有人未满分，实际出营率会低于 51.6%。金牌硬门槛已要求基础分=40 全拿。

风险 4（样本范围）：按"全部 1065 人纳入"，off/hei 自然判不出营；若只看在岗(on)老师，出营率/金牌率会显著高于 51% / 36.6%。

六、红线机制 / 升档映射 / 数据质量与待办

① 红线机制：四害作金牌排除项（不扣分）

会议定调"不扣分，用红线替代"。四害（迟到 / 早退 / 真实缺席）在计分中不做减法，而是作为金牌硬排除红线：

  • 金牌红线：迟到 ≤ 1 次、早退 = 0、真实缺席 = 0（新师 30 天绝对红线，呼应"新老师绝对不能迟到"）。
  • 出营层：迟到/早退仅通过维度2"准时完课 +2/节"做软惩罚（迟到/早退的课不计入 on_time），不硬排除。
  • 口径修正（待数据）：当前 absent_cnt 含"请假 / 系统取消"，须由海璇 8 月产品设计将请假、系统取消从"真实缺席"拨出，仅真实缺席计入红线。当前以 absent_cnt 代理并标注口径风险。

参考：历史口径下金牌老师中仅少数零三害，故金牌红线采用"容忍 range"（迟到≤1）而非绝对 0，与会议"设一个 range"一致；具体达标人数待 8 月真实数据复核。

② 升档映射（钱 / 职级侧，记录对齐）

会议明确：出营与金牌对应老师 ranking 升级。映射建议（待与现 ranking 体系对齐，不进打分模型）：

  • 出营（合格）：ranking +1 档
  • 金牌甄选（优秀）：ranking +2 档（累计，即在出营基础上再加 2）

原则：当前招聘/存量 ranking 体系以本方案为"主"、未来随本项目演进；短期用"出营+1 / 金牌+2"做温和映射，避免一次性拉满导致体系失稳。具体档位数值待确认。

③ 数据质量与下一步待办（会议提炼）

  • 蜂巢/TQ 维度3 替换：蔡老板下周稳定版数据到位后，替换 1.6×完课 模拟，重算全部阈值。
  • 四害拨请假：海璇 8 月产品设计，将请假/系统取消从真实缺席剥离。
  • 4 月数据有偏：4 月评价率刚上线偏低、且处于换血期，反馈分被低估；8 月为干净基线。
  • 8 月真实跑、9 月初复盘：用真实数据校准金牌线（200）与金牌硬门槛数值。
  • 下周三汇报（sell）：带分布模拟 + 成本测算，争取方向绿灯，细节再磨。
  • 标准固定：金牌 = 绝对线 200（对外显示封顶），不随老板百分比摇摆；老板要更多优秀 = "多拉人达到 200 分"，而非降标。
