# 阔知课程详情接口

## 1. 调用合同

```http
GET http://edu.51talk.me/api/me/TeacherCourseDetail
Accept: application/vnd.edusoho.v2+json

course_id=<阔知课程 ID>
t_id=<当前认证账号绑定的 teacher_id>
```

- 只允许教师端后端调用；前端只提交 TIDE `taskInstanceId`。
- 只在部署后端的服务器配置 `KUOZHI_DETAIL_HOST_IP=172.16.0.54`；后端客户端会保留 `edu.51talk.me` 的 Host/SNI 并覆盖 DNS 解析，前端站点和老师电脑不用配置。
- HTTP 200 仍可能是空数据；`id/title/task_list` 为空时按 `NO_DATA` 处理，不判完成。

## 2. 归一化规则

- `task_list` 兼容对象、数组或 `null`；数字兼容字符串和 number。
- 视频只按映射中的必修任务判断，当前完成线为 `percent = 100`。
- 考试使用 `score`：百分制直接比较；原始分按 `score / fullScore × 100` 归一化后，与 TIDE 当前发布题库的 `pass_score` 比较。
- 缺必修任务、缺通过线、字段不可解析或接口异常时失败关闭，不修改已完成终态。
- 不向前端或数据库保存上游返回的登录 URL。

## 3. 教师端接口

- `GET /api/v1/tasks/{taskInstanceId}/kuozhi-progress`：读取最近快照；从未刷新返回 `NOT_SYNCED`。
- `POST /api/v1/tasks/{taskInstanceId}/kuozhi-progress/refresh`：幂等查询与判定，需 `Idempotency-Key`、`commandId`、`expectedStateVersion`。
- 正式模式保存最小快照，全部条件达标时合法更新共享 assignment；示例模式只返回结果，不写数据库。
