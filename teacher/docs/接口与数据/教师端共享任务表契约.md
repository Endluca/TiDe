# 教师端共享任务表契约（镜像入口）

本文件不再维护第二份字段和状态机副本。唯一权威契约是：

- [`contracts/教师端共享任务表契约.md`](../../../contracts/教师端共享任务表契约.md)

教师端开发只需遵守以下边界：

1. `task_assignments` 是双方共用的唯一任务实例和当前状态事实。
2. 教师端只更新权威契约允许的执行状态字段，不创建任务，不改任务身份、内容、分值或资格。
3. 新教师的 G01–G09 由触发中心幂等初始化；个性化任务由 DTS/TASK_PLAN 物化。
4. 任务存在不等于通知已送达；没有消费方回执时只能描述为任务事实已创建。
5. 字段、状态机、权限、幂等、版本和错误码一律以根契约当前版本为准。
