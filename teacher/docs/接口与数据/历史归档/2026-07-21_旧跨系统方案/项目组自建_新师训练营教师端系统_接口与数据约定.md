## 1. 当前结论

世文与本系统不再建设任务 HTTP 下发／回传接口，改为共享 PostgreSQL 下的双向只读交换：

1. 世文通过教师安全视图提供教师身份、训练营、积分、课程归因、通知、28 类个性化 assignment，以及后续补充的 `G01` Self-intro／TESOL 审核字段；
2. 本系统后端在老师请求页面数据时读取世文安全视图，并按 `assignment_id` 幂等建立本地任务；
3. 本系统在 `tide.integration_events` 保存个性化状态和固定任务可信完成事件；
4. 本系统通过版本化只读视图发布最小事件字段，世文读取消费；
5. 双方使用独立 Schema、独立账号和最小权限，不写对方业务表。

浏览器、教师端前端和嘉荷任务扩展只能调用本系统教师端 HTTP API，不能直接连接 PostgreSQL。

## 2. 数据所有权

| 数据 | 权威方 | 跨系统方式 |
|---|---|---|
| 28 类个性化任务触发、原因、优先级、截止时间 | 世文 | 本系统只读世文 assignment 安全视图 |
| 个性化任务执行过程和本地完成判定 | 新师训练营 | 只保存在 `tide` Schema |
| `G01–G10` 内容、执行和可信完成事实 | 新师训练营 | 世文只读本系统完成事件发布视图 |
| `G01–G10` 计分 | 世文 | 按发布事件幂等结分，本系统不写分值 |
| 教师身份、课程、五维、总分、出营和金牌 | 世文 | 本系统只读世文教师安全视图 |
| 账号、邮箱验证和 `teacher_id` 绑定 | 新师训练营 | 注册时只读确认世文教师存在 |
| 任务答案、清单、视频心跳和任务照片／截图证据 | 新师训练营 | 不进入跨系统发布视图 |
| `G01` Self-intro／TESOL 审核状态 | 世文教师安全视图（上游原始审核系统仍为事实来源） | 本系统读取并保存安全投影，不接收或保存原始视频、资质文件 |
| `G08–G10` 及其他视频类任务的素材、观看进度和完成判定 | 新师训练营 | 全部在本系统内完成；不读取外部培训完成标签，原始观看记录不进入跨系统发布视图 |
| 课程视频、题库、原生图文和示例图片 | 新师训练营 | 开发期本地配置；正式环境通过公共 OSS／CDN 提供，不走教师证据上传接口 |
| AI FAQ、反馈和 FAQ Gap | 新师训练营 | 不提供给世文 |
| 消息正文 | 世文 | 本系统只读；首次打开状态仅保存在本系统 |

产能成长 10 分仍由世文在 `peak_slot_cnt >= 40` 首次达成时结算并永久锁定，不是任务，也不读取 `S01–S05` 状态。

## 3. 数据库拓扑与权限

正式环境可以是同一个 PostgreSQL 数据库，但“同库”不等于“同表”或“同账号”。

```text
公司 PostgreSQL
├─ shiwen Schema
│  ├─ 世文业务表（世文读写）
│  └─ 教师安全视图（TIDE 只读）
└─ tide Schema
   ├─ TIDE 业务表（TIDE 读写）
   └─ 世文发布视图（世文只读）
```

权限要求：

- `tide_app`：读写 `tide` 业务表；只读世文批准的安全视图；不能写世文表。
- `shiwen_app`：读写世文业务表；只读 `tide` 版本化发布视图；不能写 `tide` 业务表。
- 只读授权由数据库管理员执行，不在应用启动时自动提权或创建生产账号。
- 业务代码保留 `TIDE_DATABASE_URL` 和 `SHIWEN_READ_DATABASE_URL` 两个连接配置；生产可以指向同一数据库，开发可以指向不同实例。
- 前端、日志、仓库和客户端产物不得出现数据库密码或完整连接串。

## 4. 世文 → 本系统：安全视图读取

### 4.1 教师业务数据

本系统按页面请求实时读取以下教师安全数据：

- 教师身份和训练营身份；
- `teacher_metric_snapshots.public_total_score` 及五维安全结果；
- `score_accounts / score_entries` 的教师可见积分事件；
- `lesson_facts / lesson_dimension_scores` 的逐课归因；
- 通知标题、正文、有效期和关联任务；
- 28 类个性化任务 assignment。
- `G01` Self-intro／TESOL 的教师安全审核状态和来源更新时间；对应字段由世文后续补充。

世文正式安全视图名称和字段类型仍待确认。应用只能通过 `ShiwenTeacherReadAdapter` 和 `ShiwenAssignmentReadAdapter` 访问，不得让业务模块依赖世文原始表名。

读取成功后可以保存最近一次安全投影，并记录来源版本、来源更新时间、读取时间和数据截至时间。读取失败时：

1. 有最近成功投影：返回缓存并标记数据时间；
2. 无投影：返回 `503 SOURCE_UNAVAILABLE`；
3. 不使用 Mock 冒充真实教师数据；
4. 不根据本地任务进度推算世文积分或业务结论。

### 4.2 `G01` 外部审核状态

`G01` 不读取个性化 assignment，也不接收外部原始材料。世文后续提供的教师安全字段至少需要表达：

```text
teacher_id
self_intro_review_status
tesol_review_status
source_updated_at
```

具体字段名和上游状态枚举仍待世文冻结；本系统通过适配器映射为教师可见的“等待结果／审核中／已通过／需修改／暂不可用”等状态，不让页面依赖世文原始字段名。

- 只有 Self-intro 与 TESOL 两项均映射为“已通过”时，本系统才生成 `G01` 可信完成事实。
- 字段尚未提供、读取失败、状态为空或出现未知枚举时，不自动完成；有最近成功投影时展示缓存和数据时间，无缓存时显示“等待数据同步／暂不可用”。
- 本系统只保存教师安全状态、来源版本和时间，不读取、缓存或发布 Self-intro 视频、资质文件及外部审核原文。
- `G01` 完成后仍只向世文发布固定任务最小完成事件，不把两项审核明细写入发布视图。

### 4.3 个性化 assignment

世文 assignment 安全视图至少提供：

```text
assignment_id
teacher_id
task_code
title
why
what_to_do
completion_standard
outcome
priority
due_at
source_updated_at
```

规则：

- 范围是 `S01–S05` 和 23 个 `P-*`，共 28 类，全部 0 分。
- `assignment_id` 是公开幂等键；`publication_id` 等内部字段不暴露。
- 相同 `assignment_id`、相同 `payload_hash` 复用同一本地任务实例。
- 相同 `assignment_id`、不同内容视为合同冲突，不静默覆盖；内容变化时世文生成新 `assignment_id`。
- `teacher_id` 必须与注册绑定使用的稳定 ID 同源。
- `why` 不包含学生信息、投诉原文、处罚、内部阈值、SQL 或原始证据。
- `outcome` 明确个性化任务为 0 分。
- 老师刷新页面时执行增量读取；未刷新不影响已保存的本地任务状态。

任务具体流程、表单、题目、校验和教师体验由嘉荷负责；公共后端只负责读取、幂等映射、权限、状态存储和事件发布。

## 5. 本系统 → 世文：版本化发布视图

`tide.integration_events` 是本系统跨系统任务事件的权威日志。真实事件写入后不可更新或删除，并在同一事务中与本地任务状态／可信完成事实提交。

世文只读取以下两个视图，不读取 `integration_events.payload` 或其他 `tide` 业务表。

### 5.1 个性化任务状态视图

视图：`tide.shiwen_personalized_status_events_v1`

```text
provider_event_id
assignment_id
external_task_id
task_code
status
sequence
reason_code
result_code
occurred_at
published_at
```

- 只包含 `data_origin=REAL` 和 `event_type=PERSONALIZED_STATUS`。
- `provider_event_id` 全局唯一。
- `assignment_id + sequence` 唯一，`sequence` 对同一 assignment 单调递增。
- 普通状态为 `VIEWED / IN_PROGRESS / SUBMITTED / UNDER_REVIEW / COMPLETED / FAILED / EXPIRED / WAIVED / CANCELLED`。
- `reason_code` 仅用于失败、过期、豁免和取消。
- `result_code` 仅允许 `P-REL-03 + COMPLETED` 使用 `CAN_CONTINUE / CANNOT_CONTINUE`。
- 个性化任务始终为 0 分，视图不提供任何分值字段。

### 5.2 固定任务可信完成视图

视图：`tide.shiwen_fixed_task_completion_events_v1`

```text
provider_event_id
external_task_id
teacher_id
task_code
completed_at
published_at
```

- 只包含 `data_origin=REAL` 和 `event_type=FIXED_TASK_COMPLETED`。
- `task_code` 只允许 `G01–G10`。
- `teacher_id + task_code` 对真实事件唯一，同一老师同一固定任务终身最多结分一次。
- 只表达可信完成，不提供过程状态、分值、`camp_id` 或原始任务数据。

### 5.3 世文消费规则

- 世文在自身 Schema 保存消费游标、处理结果和计分幂等记录，不写 `tide` 表。
- 推荐按 `published_at + provider_event_id` 稳定分页；重复读取必须安全。
- 先按 `provider_event_id` 去重，再执行 assignment 顺序控制或固定任务结分。个性化 `sequence` 使用产生该对外状态的本地 `state_version`，严格递增但允许因纯本地进度保存而不连续。
- 未消费或消费失败不影响本系统已经保存的教师任务结果。
- 事件不可原地修改；需要业务纠错时新增正式纠错事件类型和版本，不直接改历史数据。本期暂未定义纠错事件。

## 6. 本系统教师端 HTTP 合同

教师端任务、文件、My TIDE 和通知 HTTP 合同位于[`backend/contracts`](../../backend/contracts/README.md)：

- 注册使用 `POST /api/v1/auth/register`；只有世文安全视图存在对应 `teacher_id` 且邮箱、教师编号均未绑定时才创建待验证账号；
- 邮箱验证使用一次性原始令牌，数据库只保存令牌哈希；确认与重新发送分别使用 `/api/v1/auth/email-verification/confirm` 和 `/api/v1/auth/email-verification/resend`；
- 重新发送接口无论邮箱是否存在都返回相同受理结果；验证令牌有有效期、只能成功使用一次，已成功验证的同一令牌可幂等返回 `ALREADY_VERIFIED`；
- 登录签发短期 Bearer JWT 和一次显示的刷新令牌；刷新时必须轮换，数据库只保存刷新令牌哈希；注销后服务端立即拒绝该会话的现有访问令牌；
- 密码重置申请不泄露邮箱是否存在；重置令牌只能成功使用一次，密码更新与撤销该账号全部既有会话在同一事务完成；
- `GET /api/v1/me/profile` 返回当前账号邮箱和世文教师身份、训练营天数等教师安全资料；实时读取失败时只返回最近成功投影并标记 `CACHED`，没有投影时返回 `SOURCE_UNAVAILABLE`；
- `GET /api/v1/me/g01-review` 返回后端映射后的 Self-intro／TESOL 状态、是否具备完成条件和来源新鲜度；前端不得根据世文原始枚举自行判断；
- 嘉荷统一依赖 `TaskContext`，不得直连任一数据库；
- `GET /api/v1/tasks` 在一次请求内先幂等检查已发布真实固定模板，再读取世文 assignment 安全视图并返回统一列表；`GET /api/v1/tasks/{taskInstanceId}` 只返回当前老师的统一 `TaskContext`；
- `TaskContext.display` 统一返回阶段键、展示顺序、任务分值和预计时长；这些字段来自已发布模板配置，前端不按任务编码写死业务排序或分值；
- 相同 `assignment_id + payload_hash` 复用任务实例；相同 `assignment_id` 内容变化返回合同冲突，不覆盖旧任务。对应嘉荷模板未发布时返回 `ASSIGNMENT_TEMPLATE_NOT_READY`，不创建空壳任务；
- assignment 读取失败时返回已保存任务并标记 `assignmentSync.source=UNAVAILABLE`；读取成功后记录成功状态。`externalTaskId` 使用本系统首次建立的任务实例 ID，并与 `assignment_id` 永久绑定；
- 个性化任务只比固定任务增加教师安全 assignment 上下文；
- `G01` 详情读取后端映射后的 Self-intro／TESOL 教师安全状态；世文字段未就绪或状态不可识别时不得由前端推断完成；
- `G08–G10` 及其他视频类任务统一使用本系统任务步骤、视频进度和提交校验合同，不读取外部培训完成标签；视频之外的小测、清单和重试规则由任务级 PRD 与模板配置提供；
- 任务开始、进度、提交和重试分别使用既有 `/start`、`/progress`、`/submissions`、`/retry` 路由；每次写操作必须同时携带 `Idempotency-Key`、`commandId` 和 `expectedStateVersion`；
- 后端在同一事务中锁定任务、检查状态版本、保存业务变化和 `task_command_receipts` 收据。只有幂等键、命令编号、任务和请求摘要全部一致才返回首次结果；任一键被其他请求复用时返回冲突；
- `PUT /progress` 不信任客户端提交的完成百分比：视频按服务端时间、连续播放位置、媒体版本和 1 倍速保存可信进度；原生图文要求明确阅读确认；小测由后端私有答案和及格线判定；清单校验模板要求的键；设备检查校验每个配置项均为通过；上传步骤只接受当前老师、当前任务和当前步骤下状态为 `READY` 的文件；
- 进度写响应可返回当前步骤的权威 `status / percent / result`。前端必须使用该结果更新页面，不能以请求参数覆盖；公共任务读取接口不得返回答案、`answerKey`、提示词、评分 Rubric 或其他私有配置；
- 通用提交先校验步骤存在、输出类型匹配和文件已通过完整性校验，再建立 `PENDING` submission、关联受控文件并调用版本化规则处理器。公共处理器包含 `ALL_STEPS_COMPLETE` 与配置驱动的 `AI_IMAGE_REVIEW`；未注册的嘉荷专属处理器返回 `UNDER_REVIEW`，不得默认通过；
- 最终提交可以只引用已保存的权威步骤进度；后端在 attempt 中固化小测答案与分数、清单项、设备检查项和已关联图片，不能仅依据客户端本次提交的空壳完成声明；
- 校验通过时在同一事务保存 attempt、submission、completion、状态和版本；校验失败保留历史，只有嘉荷模板明确配置 `allowRetry=true` 才允许重试。`GET /api/v1/tasks/{taskInstanceId}/validation` 返回最近一次提交结果；
- 个性化任务的 `IN_PROGRESS / UNDER_REVIEW / COMPLETED / FAILED` 等对外状态与本地状态在同一事务追加到 `integration_events`；固定任务只有 `COMPLETED` 才在同一事务追加可信完成事件；
- `provider_event_id` 由本系统任务实例和状态版本稳定生成；个性化与固定任务的 `external_task_id` 都使用本地任务实例 ID。事件 payload 固定为空对象，发布视图不包含任何原始过程数据；
- 本期教师文件提交仅限任务流程明确要求的照片或截图证据；`G01` Self-intro 视频和 TESOL／教学资质不使用本系统文件接口，项目预置课程素材也不使用教师证据上传接口；
- 照片或截图先通过 `POST /api/v1/files/upload-intents` 创建与老师、任务实例和 `UPLOAD` 步骤绑定的幂等上传意图；本地联调再向 `POST /api/v1/files/{fileId}/content` 的 `file` 表单字段提交图片，最后调用 `POST /api/v1/files/{fileId}/complete` 完成服务端大小和 SHA-256 校验；
- 浏览器拍照或截屏产生的数据先转换为图片文件后走同一流程，不把 Base64 正文写入任务进度、业务表或浏览器长期存储；
- `GET /api/v1/files/{fileId}/content` 只允许当前老师读取状态为 `READY` 的私有图片，不暴露服务器路径；本地存储替换为私有 OSS 时保持这组公共合同兼容；
- FAQ 使用 `/api/v1/faq/conversations` 创建和读取当前老师会话，通过 `/messages` 发送纯文字问题，并通过 `/api/v1/faq/messages/{messageId}/feedback` 保存首次反馈；发送问题必须带 `Idempotency-Key`，同键同负载返回首次结果，同键不同负载返回冲突；
- FAQ 只检索已生效、权威级别为 `FAQ` 且允许回答的知识片段。未命中时不调用 AI，保存固定拒答并按脱敏标准问题幂等累加 `faq_gaps`；
- FAQ AI 回答必须是严格 JSON，引用编号必须属于本轮检索来源；模型拒答、调用失败或响应不合规均不得生成无来源公司口径。教师消息、助手消息、来源、反馈和 AI 调用审计分别保存；
- `POST /api/v1/support/requests` 保存 `HELP / APPEAL / RECHECK` 请求并要求 `Idempotency-Key`；`GET /api/v1/support/requests` 只返回当前老师的请求。若关联任务，不属于当前老师时统一按不存在处理；
- `POST /api/v1/client-events` 按当前老师和 `eventId` 幂等保存页面与交互分析事件；它不能修改任务状态、积分、消息已读或跨系统发布事件，属性不得包含答案、清单、图片、文件地址或敏感原文；
- My TIDE、课程和通知由本系统后端组合本地数据与世文安全视图结果；通知返回世文来源时间 `issuedAt`，本地首次打开状态只由消息打开接口修改；
- 当前 OpenAPI 开发合同覆盖 30 个公开路径；前端只通过这些 HTTP 合同访问账号、教师数据、任务、文件、FAQ、支持和埋点；
- OpenAPI 不再包含 `/integrations/shiwen/v2/assignments` 或世文机器鉴权。

本地全链路联调可以把 `SHIWEN_*_VIEW` 指向仓库提供的 `tide_mock_source.*` 安全视图，并使用显式标记的 `G01–G10`、个性化任务和 FAQ Mock Seed 覆盖全部通用任务类型；这些视图与数据只用于开发，不能进入生产配置，也不能使 `data_origin=MOCK` 的任务事件进入世文发布视图。

共享数据库集成细节见[世文集成契约](../../backend/contracts/世文集成契约.md)。

## 7. 安全、审计与 Mock

- 当前拥有广泛 CRUD 权限的临时世文账号不得进入正式应用配置。
- 发布视图不包含密码、令牌、邮箱、学生信息、原始证据、答案、清单、图片、文件地址、视频心跳或 AI 原文。
- `data_origin=MOCK` 的事件不得出现在世文发布视图中。
- 事件生成、读取失败和权限拒绝记录脱敏审计信息，不记录完整连接串或原始敏感载荷。
- 重复 assignment 不生成重复本地任务；重复事件不产生重复积分。
- 两个系统的 Schema 分别备份；发布视图和授权脚本纳入版本化迁移与恢复演练。

## 8. 其他外部依赖

### 8.1 公司 AI 网关

- AI FAQ 与必修任务图片审核共用网关适配器和通用调用记录，但不共用业务数据。
- 初始模型为 `doubao-seed-2-0-lite`，密钥仅保存在后端环境配置。
- AI FAQ 一期只接收文字；任务图片审核的提示词、标准和体验由对应任务级 PRD 决定。
- AI FAQ 不接受文件字段，也不读取任务提交图片；问答与图片审核只共用 AI 网关和 `ai_runs`，不共用会话、业务结论或素材。
- `AI_GATEWAY_ENABLED` 默认关闭；启用时必须配置 `AI_GATEWAY_API_KEY`。网关地址、provider、model、biz_id、biz_type、上传 bucket、上传 provider 和超时均由后端环境变量提供。
- 图片审核规则类型为 `AI_IMAGE_REVIEW`。模板配置至少提供 `stepKey / criteriaVersion / criteriaKeys / systemPrompt / userText`，可关联已生效的 `promptVersionId`；这些配置由嘉荷的任务级 PRD 和模板负责，公共后端不内置具体任务标准。
- 本系统仅允许提交中已绑定、状态为 `READY`、属于当前老师与任务的图片进入审核。网关返回必须为严格 JSON，包含 `decision / teacherReason / confidenceSummary / criteria`，且标准键与配置完全一致。
- `PASS` 对应可信 AI 审核完成，`RETRY` 对应可解释的未通过，`ERROR` 或任何技术故障对应 `UNDER_REVIEW`。技术故障不会生成老师失败状态。
- `ai_runs` 不保存密钥、图片、完整提示词或模型原文；只保存哈希、网关引用、模型、耗时、用量和错误码。业务审核结论保存在 `image_reviews / image_review_items`，不会进入世文发布视图。

### 8.2 公司邮件服务

- 后端调用 `POST http://mg.51talk.me/api/v1/msg/send`。
- 固定配置和凭据只在后端环境变量；动态变量为 `email / reset_url / expires_in_minutes`。
- Postman Cookie、User-Agent、Connection 和本地 hosts 映射不进入业务代码。

### 8.3 OSS

- 课程视频、题库、原生图文和示例图片由项目组开发时配置；开发期使用本地受控资源，正式环境使用公共 OSS／CDN 和版本化素材引用，不走教师证据上传接口。
- 老师提交的任务照片或截图使用私有 OSS 和临时签名访问，不与公共课程素材混放；`G01` 外部审核材料不进入本系统存储。
- OSS 审批前，教师照片／截图证据使用 Mac mini 专用私有目录和后端鉴权接口；上传意图绑定当前账号、任务实例和上传步骤，默认 15 分钟过期。
- 本期教师上传 MIME 只允许任务步骤配置批准的图片类型；最大字节数和有效期由后端环境与任务步骤共同限制。接收内容与声明的 MIME、大小或 SHA-256 不一致时进入隔离状态，不能用于任务提交。
- PostgreSQL 只保存图片元数据、对象键、上传意图和访问审计；不保存二进制或 Base64，也不向世文发布图片地址或内容。
