## 需要世文补充的字段字典

以下字段在 SQL 中是自由 JSON，无法从建表语句推导出内部数据名、类型、是否必填和枚举值：

- 所有表中的 `payload`；
- `task_templates.action_schema`；
- `idempotency_records.response_payload`；
- `provider_calls.request_payload`、`provider_calls.result_payload`。

联调时还需要世文提供：各状态字段的枚举、教师端可见字段白名单、下发／回传事件样例，以及 `assignment_revision`、`execution_contract_version` 与接口 `task_version` 的对应关系。
