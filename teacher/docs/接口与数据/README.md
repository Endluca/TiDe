# 接口与数据目录说明

## 当前唯一依据

1. [教师端共享任务表契约](教师端共享任务表契约.md)
2. [教师端积分与课程读取对照表（根目录唯一当前契约）](../../../contracts/教师端积分与课程读取对照表.md)
3. [TIT 成长系统数据库表结构（根目录唯一当前文档）](../../../docs/数据库表结构.md)
4. [教师端系统主 PRD](../PRD/新师训练营_教师端系统_PRD.md)
5. [教师端自有表结构](教师端自有表结构.md)（当前迁移与业务边界说明）

当前口径：

- 两端共用同一个 PostgreSQL，直接共享 `task_templates` 和 `task_assignments`。
- 共享库的当前固定任务为连续编号的 `G01–G09`；G04 是 `Lesson Preparation`，隐藏 G00 只读保留。教师端只更新契约允许的执行状态字段。
- 世文任务触发中心读取合法 `COMPLETED`，并向 `score_entries` 幂等结分。
- 教师端总览和逐课明细分别只读 `teacher_scorecard_current / teacher_lesson_score_current`，不读取原始积分表或评分配置自行计算。
- 基础分上限 40，只由产能成长实际得分（最高 10）和必修任务实际得分（最高 30）组成；可获得积分只统计未完成 G 任务，合计为 0 时隐藏；不再展示待确认积分。
- 不再建设任务 HTTP 下发／回传接口，不再保留第二套任务副本。
- 当前教师可见固定任务为 G01–G09，其中 G02 为 Platform Policies、G03 为 Student Types、G04 为首课准备、G05 为 TTP、G06 为 ME、G07 为 Reliability、G08 为 Cocos、G09 为 SET；隐藏 G00 和 Free Trial 不进入当前任务。当前 13 类个性化改善模板由任务触发中心根据真实数据创建 assignment，教师端不默认全量分配。
- G01 只读取 TESOL 真实状态，在阔知完成课程 407 的考试，并在站内完成 Essay 确认和完成证明提交；四项全部满足后完成，不展示 Self-intro。G04 在站内完成课件准备确认和授课环境拍照 AI 检查，不包含设备网络检测。G02 使用后端按 execution 版本提供的原生政策文档；G05–G08 的视频／测试只使用阔知 iframe，G09 同样只允许阔知执行但映射发布前保持内容待配置。
- 固定任务和个性化任务的 Why／How／完成标准／完成收益均直接读取世文共享 assignment 与模板字段，不使用本地固定文案覆盖。
- 教师端自身产生的系统通知保存在 `tide.system_notifications`，不与外部业务提醒混表。

## 目录分类

- `教师端共享任务表契约.md`：两端如何共享和受限写入任务表。
- `教师端积分与课程读取对照表.md`：历史链接兼容入口，正文只在根目录 `contracts/`。
- `数据库表结构.md`：历史链接兼容入口，`public` Schema 正文只在根目录 `docs/`。
- `教师端自有表结构.md`：教师端 `tide` Schema 当前迁移、核心表职责和边界。
- `阔知自动登录接口.md`：阔知课程免登录入口、签名规则、安全边界及 POC 待确认项；当前不替代共享任务契约。
- `历史归档/`：2026-07-21 及更早的接口、安全视图、事件回传和旧 Schema 方案，仅供追溯。
- `邮件模板/`：教师端邮件 HTML 模板。

实际连接世文数据库后，如实际 Schema 与当前文档不一致，先记录差异并与世文确认，不自行修改业务表。
