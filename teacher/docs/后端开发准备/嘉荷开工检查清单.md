# 嘉荷任务开发开工检查清单

每个固定必修任务或个性化任务开始开发前确认：

- [ ] 任务已在任务索引登记，负责人和任务编码明确。
- [ ] 已阅读对应任务 PRD，正式口径与 Mock 已区分。
- [ ] 任务所需数据可由公共任务合同表达。
- [ ] 只修改任务 PRD 授权的前端、配置或任务专属后端目录。
- [ ] 不直接读取本系统或世文数据库。
- [ ] 不自行修改公共 API、数据库迁移、世文协议或跨系统状态。
- [ ] 个性化任务只展示教师安全原因，不展示内部证据、触发阈值或积分收益。
- [ ] Mock 使用 `.invalid` 邮箱、`MOCK-*` 标识，不会进入真实世文发布视图。
- [ ] 已覆盖加载、空数据、失败、重试和无权限状态。
- [ ] 完成后验证 PC、390px 移动端和其他任务不受影响。

字段或能力不足时，按 `COLLABORATION_STANDARD.md` 2.4 节提交扩展需求，由 Echo 统一修改公共合同。
