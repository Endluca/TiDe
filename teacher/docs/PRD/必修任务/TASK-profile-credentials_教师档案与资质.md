## 1. 任务目标与边界

G01 包含四项完成条件：

1. TESOL 已完成；
2. 阔知课程 407 的考试任务完成；
3. TESOL Essay 已完成；
4. 完成证明已提交。

TESOL 状态读取世文 `teacher_source_wide.is_cpl_tesol` 可空状态字段。`NULL` 表示上游尚未提供，不能当成未完成或完成。考试在当前任务页内嵌的阔知课程 407 完成；Essay 完成确认和完成证明提交在教师端系统内完成。`is_self_introduce` 仍可作为教师资料来源事实保留，但不属于 G01，不在 G01 页面读取、展示或参与完成判定。

本系统不保存 TESOL Essay 原文，也不保存阔知题目、答案或作答记录。Essay 当前使用完成确认；完成证明支持清晰图片或 PDF。

## 2. 页面结构与流程

```text
进入任务
  → 查看四项完成状态
  → 查看 TESOL 来源状态
  → 在页面内嵌阔知课程完成考试
  → 确认 TESOL Essay 已完成
  → 上传完成证明
  → 四项全部满足
  → 提交并更新 G01 为 COMPLETED
```

四项状态在页面顶部同时展示。阔知不提供新窗口或其他外跳按钮；已完成项不要求重复操作。

## 3. 完成判定

```text
TESOL = APPROVED
AND 阔知课程 407 / 任务 2158 的 percent = 100
AND Essay 完成确认 = true
AND 完成证明已提交
→ G01 COMPLETED
```

任一项未满足时不得完成。阔知同步本身不自动完成 G01，必须等待另外三项条件一起通过。前端显示的勾选、百分比或本地状态不能替代后端校验。

考试完成只以阔知返回的 `percent=100` 判定；`score` 和 `test_times` 仅作为展示与审计证据，不设置站内通过线，也不做分数归一化。

## 4. 数据与隐私边界

- G01 只读取 TESOL 的安全状态、来源更新时间和同步新鲜度，不读取 Self-intro 状态；
- 阔知只保存课程同步快照、映射版本和完成结论，不保存题目、答案或作答；
- Essay 只保存“已完成”的清单确认，不保存 Essay 正文；
- 完成证明的文件元数据和校验结果保存在 PostgreSQL，文件二进制保存在私有文件存储；
- 来源状态不可用或阔知尚未同步时显示明确状态，不得用 Mock 自动通过。
