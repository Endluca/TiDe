## 1. 任务目标与边界

G01 包含五项完成条件：

1. Self-intro 已完成；
2. TESOL 已完成；
3. 61 题全部完成并达到发布配置通过线，当前配置为 80%；
4. TESOL Essay 已完成；
5. 完成证明已提交。

Self-intro 与 TESOL 状态读取世文 `teacher_source_wide` 的两个可空状态字段。`NULL`
表示上游尚未提供，不能当成未完成或完成；61 题、Essay 完成确认和完成证明提交在教师端系统内完成。

本系统不接收 Self-intro 原视频，也不保存 TESOL Essay 原文。Essay 当前使用完成确认；完成证明支持清晰图片或 PDF。

## 2. 页面结构与流程

```text
进入任务
  → 查看五项完成状态
  → 查看 Self-intro 与 TESOL 来源状态
  → 完成 61 题并达到通过线
  → 确认 TESOL Essay 已完成
  → 上传完成证明
  → 五项全部满足
  → 提交并更新 G01 为 COMPLETED
```

五项状态在页面顶部同时展示。未完成项保留明确入口；已完成项不要求重复操作。

## 3. 完成判定

```text
Self-intro = APPROVED
AND TESOL = APPROVED
AND 61 题全部作答且得分 >= 发布配置通过线
AND Essay 完成确认 = true
AND 完成证明已提交
→ G01 COMPLETED
```

任一项未满足时不得完成。前端显示的勾选、百分比或本地状态不能替代后端校验。

61 题允许按发布配置重试。当前通过线为 80%；后续如嘉荷发布新版本，以版本化任务配置为准，不在页面逻辑中另写一套数值。

当前执行配置仍将 61 题题库标记为 `mock: true`。站内答题、判分和进度闭环可用于受控测试，但正式题库未复核发布前不得把 G01 标为生产内容已就绪。

61 题全部在当前任务页内逐题作答和提交，不提供外部考试入口。原题库中要求打开 Google Form 的说明题已改写为站内 Essay 确认操作，并使用新的题库版本，避免老师离开训练营。

## 4. 数据与隐私边界

- Self-intro 与 TESOL 只读取安全状态、来源更新时间和同步新鲜度；
- 61 题答案、得分、重试记录和提交快照保存在教师端 `tide` Schema；
- Essay 只保存“已完成”的清单确认，不保存 Essay 正文；
- 完成证明的文件元数据和校验结果保存在 PostgreSQL，文件二进制保存在私有文件存储；
- 来源状态不可用时显示“暂不可用”，不得用 Mock 自动通过。
