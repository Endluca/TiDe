## 1. 任务目标与素材

老师在新师训练营内完成 Cocos 视频学习和小测。任务页使用嘉荷的视频＋小测交互，后端保存每一章的可信观看进度、答案草稿、提交快照、得分和重试历史。不再使用外部培训标签代替站内完成证据。

- 课程 630 的 5 道题已作为 `cocos-training / course-630-2026-07` 发布到数据库；7 章视频仍按版本化素材引用加载；
- 章节、视频、题库、通过线、重试次数和失败后是否需要重看视频，全部以嘉荷发布的版本化任务配置为准；
- 当前七章 v2 视频和 5 道题由版本化配置引用，使用站内播放器、后端观看进度和后端判分。业务编码从重排前 G09 调整为 G08，但 `g09-*` 步骤 key、媒体版本、物理路径和题库 key 保持稳定。

## 2. 主流程与完成判定

```text
进入任务
  → 按配置顺序完成全部视频章节
  → 每章由后端心跳校验首次完整观看
  → 视频完成后解锁小测
  → 后端按嘉荷配置判分和校验重试规则
  → 视频与小测全部达标
  → G08 assignment 更新为 COMPLETED
```

视频固定 1 倍速；首次完整观看前禁止拖动，中途退出后从最后有效位置续播。小测正确答案不返回学习中的前端；提交后按配置展示得分、解析和重试入口。
