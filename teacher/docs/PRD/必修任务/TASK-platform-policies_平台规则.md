## 1. 产品结论

G02 不再使用阔知课程 `499`、视频任务 `2702`、考试任务 `2715` 或试卷 `415`。老师直接在 TIDE 任务详情页阅读 `Overseas NT Policies`，不打开钉钉文档预览或下载页，也不显示阔知 iframe、视频、答题区、分数或人工“完成”按钮。

正式任务只有一个 `DOCUMENT` 步骤：`g02-policy-document`。TIDE 展示内化后的完整政策正文和原文内嵌图片，并用已发布的内容版本和正文 Markdown SHA-256 绑定阅读进度，避免把旧文档进度误用于新版本；内嵌图由独立资产 SHA-256 校验。

## 2. 用户流程

1. 老师打开 G02，看到 TIDE 原生的 `Overseas NT Policies` 标题、全文和当前阅读百分比。
2. 老师在文档区域内阅读；系统按阅读位置单调累加进度，并在进度至少增加 5 个百分点或到达末尾时保存。
3. 刷新、退出或重新登录后，从后端已保存的最高进度继续；向上滚动不能降低已保存进度。
4. 当可视区域到达文档末尾（允许 16 px 计算容差）时，前端上报 `readPercent=100` 与 `reachedEnd=true`。
5. 后端核对当前步骤的 `contentVersion`、`contentHash`、整数百分比及末尾标记；将 `reached_end=true`、步骤 `COMPLETED`、标准提交证据和共享 assignment 完成状态放在同一事务提交。
6. 后端按 `ALL_STEPS_COMPLETE` 规则验证并幂等更新共享 assignment；老师无需再点击完成按钮，也不依赖第二次前端提交。完成后仍可回看全文。

## 3. 完成规则

- 只有当前发布版本的正文滚动到末尾，且后端保存的文档步骤为 `100% / reachedEnd=true`，才满足 G02 的完成条件。
- `readPercent=100` 与 `reachedEnd=true` 必须同时出现；任一缺失、百分比不是整数、内容版本或哈希不匹配时，后端以 `DOCUMENT_PROGRESS_INVALID` 失败关闭。
- 只打开任务、只加载页面、阅读到 99%、打开正文里的链接，均不完成任务。
- G02 不设测验、及格分、人工确认或人工审核，也不读取阔知进度。
- 任务已合法进入 `COMPLETED` 后保持不可回退终态；重复保存、重复提交或刷新不得重复完成、重复结分。

## 4. 内容与安全边界

- 教师运行页面加载仓库内受版本控制的正文，不把原钉钉节点或分享地址作为运行时依赖；源节点 ID 与更新时间只用于内容审计，不向老师暴露。
- 正文中的可访问链接必须经过发布审核，并以新窗口安全打开；点击外链不作为完成证据。
- 原文内嵌图片已转换为 TIDE 受版本控制的发布资产，并以独立 SHA-256 与正文随同一内容版本验收；教师页面不依赖不可访问的钉钉内部资源地址。
- 发布正文变更时必须生成新的 `contentVersion` 和 `contentHash`，并明确旧未完成进度的迁移策略；不得原地覆盖已发布版本后继续沿用旧进度。
- 文档正文和进度不写入共享 `task_assignments`；共享表只保存任务当前状态。过程数据保存在教师端 `tide.task_step_progress`。

## 5. 异常与恢复

- 进度保存失败时保留当前页面进度并显示可重试提示；技术失败不得把老师判为未通过或完成。
- 若标准提交链校验或数据库写入失败，整个读完事务回滚；页面保留本次本地进度并允许重试，不会在数据库留下“已读完但 assignment 未完成”的悬挂状态。
- 服务端返回旧版本、错误哈希或异常进度时，客户端不得自行修正为完成，应重新读取当前执行配置并提示重试。
- 文档区域必须支持鼠标滚轮、触控和键盘滚动；PC 与移动端均能到达清晰可识别的“文档已到底”标记。

## 6. 验收用例

- [ ] G02 任务页显示 `Overseas NT Policies` 的已发布完整正文，不出现阔知 iframe、视频、测验、分数、钉钉预览／下载入口或手动完成按钮。
- [ ] 首次打开但未滚动到底不会完成；滚到 99% 仍不会完成。
- [ ] 滚动到末尾后保存 `100% / reachedEnd=true`，自动提交并把 assignment 合法更新为 `COMPLETED`。
- [ ] 中途刷新或重新登录后恢复后端最高阅读进度，向上滚动不会倒退。
- [ ] 内容版本、哈希、百分比或末尾标记任一无效时，后端拒绝完成。
- [ ] 读完事务任一步失败时数据库不留下半完成状态；前端可直接重试，不需要重新阅读。
- [ ] 同一完成请求重放不会重复写完成事实或重复结算 2 分。
- [ ] 已完成老师仍可回看正文，状态和积分事实不会因内容回看而回退。
- [ ] 原文内嵌图片与正文完整显示，链接逐项完成发布审核；不存在指向不可访问内部资源的正式内容。
