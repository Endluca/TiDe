# 任务 PRD｜Platform Policies 平台规则

## 0. 文档信息

| 项目 | 内容 |
| --- | --- |
| 任务 ID / 编码 / 分值 | `platform-policies` / `G02` / 2 分 |
| 完成方式 | 阔知课程视频＋考试 |

## 1. 用户流程

老师从 TIDE 免登打开阔知课程，在阔知完成学习后回到 TIDE 刷新进度。TIDE 不再提供本地规则文档、答题或判分页面。

## 2. 完成规则

- 视频 `2702` 的 `percent = 100`；
- 考试 `2715` 的阔知 `percent` 为 100；`score` 仅作为展示与审计证据；
- 两项都达标后，后端才可幂等完成 G02 assignment；只打开课程不完成任务。

## 3. 验收

- 前端不提交 `teacher_id`、`course_id`，不复制完成规则；
- 空数据、缺少必修项、分数异常或阔知不可用时不判完成；
- 重复刷新不重复完成或结分；刷新、重新登录后可读取最近一次服务端快照。
