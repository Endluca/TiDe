## 1. 任务目标与素材

老师在站内完成 Reliability 培训和小测，了解出勤与可靠性要求。教师端不展示内部风险标签或阈值。

- 当前候选素材为课程 595 的两段视频；
- 两段视频均在当前任务页内播放，不跳转外部课程；
- 当前发布 5 道 Mock 题和 80% 通过线，用于完整验收站内答题、判分和重试；
- 当前两段 v2 视频由版本化配置引用；5 道题仍明确标注为 Mock，正式题库发布后创建新版本替换。业务编码从重排前 G08 调整为 G07，但 `g08-*` 步骤 key、媒体版本、物理路径和题库 key 保持稳定。

## 2. 主流程与完成判定

```text
进入任务
  → 按嘉荷配置顺序完成培训视频
  → 后端验证首次完整观看
  → 完成小测
  → 达到发布版本通过线
  → 后端幂等完成 G07 assignment
```

首次观看禁止倍速和向前拖动；视频进度、答题草稿、提交快照、得分和重试记录由后端保存。固定 G07 与个性化 Reliability 复训可复用执行引擎，但必须使用各自的 assignment 和版本配置。
