## 1. 最新口径

TTP Orientation 保留 `Learning checklist`，同时必须在任务页内提供当前 v2 TTP 视频播放器。业务编码已从重排前 G06 调整为 G05，但视频路径、`g06-*` 步骤 key 和 `mediaVersion` 保持稳定，以便续接既有观看与清单进度。

本轮原型不得：

- 跳转外部课程页面播放视频；
- 只展示文字清单而移除视频播放器；
- 使用外部课程标签或手工同步冒充站内观看进度。

## 2. 学习清单

老师先在本页完整观看 TTP 视频，再理解并确认以下 5 个关键场景：

1. TTP 与固定学员、开放时段和排期承诺的关系；
2. Shift Management 与 Auto Open Slot 的使用场景；
3. 开放时段的承诺周期与成熟日；
4. 已预约时段的履约要求，以及排期变化时应尽早处理；
5. 持续维护 MyPage 可授课时段，并知道在哪里寻求支持。

## 3. 主流程与完成判定

```text
进入任务 → 在本页完整观看 TTP 视频 → 阅读 5 个业务场景 → 逐项勾选确认 → 完成任务
```

只有视频完整观看且嘉荷当前发布配置中的全部清单项都确认后，后端才能幂等完成 G05 assignment。打开页面、只播放部分视频、只阅读内容或离开页面均不会自动完成。视频位置、完整观看结果、清单明细和确认状态由后端保存，刷新、重新登录或换设备后可恢复。
