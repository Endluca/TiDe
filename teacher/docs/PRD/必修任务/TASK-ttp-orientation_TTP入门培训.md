## 1. 用户流程

老师从 TIDE 免登打开阔知课程，在阔知完成 TTP 视频和 Quiz 后返回 TIDE 刷新进度。TIDE 不再使用本地播放器或 Learning checklist 作为完成条件。

## 2. 完成规则

- 视频 `3794` 的 `percent = 100`；
- 考试任务 `3795`（试卷 `585`）的 `percent = 100`；分数仅作为展示与审计证据；
- 两项都达标后后端才可幂等完成 G05 assignment；只打开课程、部分观看、考试未完成或没有返回数据均不完成。

## 3. 验收

- 刷新后展示阔知视频和考试进度；
- 空数据、缺少任一必修任务或字段异常时失败关闭；
- 重复刷新不重复完成或结分。
