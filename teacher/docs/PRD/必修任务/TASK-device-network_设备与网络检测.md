## 1. 任务目标与系统边界

该任务用于让老师在首课前查看 AC 回传的最新设备与网络检测结果。检测本身在 AC 完成；新师训练营只展示回传状态、结果来源和最近更新时间。

以上是旧版边界。当前 G04 只完成课件准备确认和一张授课环境照片检查，不再包含摄像头／麦克风／网络检测；重排前旧 G05 以隐藏 G00 只读保留，不再独立展示。

## 2. 页面位置与主流程

```text
Tasks → Module 01 / Day 1–7 → Device & Network Check
  → 查看 AC 回传的最新状态
  → 查看结果来源和最近更新时间
  → 未通过或缺失时按提示前往 AC／联系支持
  → AC 回传“已通过”或批准的等价结果
  → 按历史约定数据流程更新重排前 G02 assignment
```

页面至少展示 AC 检测名称、当前状态、结果来源、最近更新时间、完成条件和帮助入口。回传缺失、延迟或异常时，使用教师可理解的等待／处理提示，不在前端伪造通过结果。

## 3. 状态与完成判定

| AC 回传结果 | 共享任务状态 | 教师端展示 |
| --- | --- | --- |
| 尚未回传 | `ASSIGNED / VIEWED` | 等待 AC 结果 |
| 检测处理中 | 保持来源状态 | 处理中，并展示最近更新时间 |
| `PASSED` 或批准的等价结果 | `COMPLETED` | 已通过 |
| 未通过／需要重测 | 可恢复状态 | 需要处理，并提示在 AC 重测 |
| 回传异常 | 保持当前可恢复状态 | 暂时无法获取结果，请稍后查看或联系支持 |

完成规则：

```text
AC 回传 PASSED 或批准的等价结果
= 任务完成
```

这是历史方案：训练营不保存本机检测过程或照片，重排前 G02 assignment 的状态以约定的 AC 回传和共享状态机为准。当前 G04 以现行站内执行配置为准。
