## 1. 任务目标与范围

老师在新师训练营内完成 SET 教学基础视频和小测。任务页使用嘉荷的视频＋小测交互，后端保存可信观看进度、答案草稿、提交快照、校验结果和重试历史。不再使用外部培训或能力标签代替站内完成证据。

当前正式视频和题库尚未发布，但原型必须保留可播放、可答题的站内闭环。当前使用一个明确标注的 Mock 视频槽和 5 道 Mock 题，80% 通过；正式素材发布后创建新版本替换，不改变站内播放和答题交互。

业务编码从重排前 G10 调整为 G09，但 `g10-*` 步骤 key、Mock 媒体版本、物理路径和题库 key 保持稳定，以免切断已存在的受控测试进度。

## 2. 任务流程

```text
任务触发中心幂等初始化 G09 assignment
  → 老师在站内按配置完成全部视频章节
  → 后端通过视频心跳校验首次完整观看
  → 视频完成后解锁小测
  → 后端按嘉荷配置判分并执行重试规则
  → 视频与小测全部达标
  → G09 assignment 更新为 COMPLETED
```

## 3. 完成判定

```text
所有配置视频章节已通过后端完整观看校验
+ 小测达到嘉荷配置的通过标准
= COMPLETED
```

视频固定 1 倍速，首次完整观看前禁止拖动，退出后从后端记录的最后有效位置续播。小测正确答案不在学习过程中下发给前端，最终完成以后端校验结果为准。
