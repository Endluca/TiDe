## 1. 任务目标与范围

G09 只在 TIDE 任务页 iframe 内嵌阔知课程 658《Skills Training for Effective Performance》。视频播放、Quiz 作答和原始结果由阔知负责，TIDE 只查询版本化映射中的六项必修结果并更新共享 assignment。

课程还包含三份 Job Aid 文档。它们保留在阔知课程的正常学习顺序中，但当前阔知详情契约只对视频和考试返回可用于完成判定的 `percent`，因此文档不单独作为 TIDE 完成条件，也不在 TIDE 创建本地阅读步骤。

## 3. 任务流程

```text

  → TIDE 在任务页 iframe 内打开阔知课程 658

  → 六项 percent 均为 100
  → G09 assignment 幂等更新为 COMPLETED
```

## 4. 完成判定

- 视频 `3826 / 3831 / 3836` 的 `percent` 均为 100。
- Quiz `3829 / 3832 / 3834` 的 `percent` 均为 100；`score` 和 `test_times` 仅作展示与审计证据。
- 任一必修任务缺失、进度不可解析或接口异常时失败关闭，不把异常判为完成，也不回退已完成终态。
- 课程中的 Job Aid 文档不单独参与 TIDE 完成判定。
