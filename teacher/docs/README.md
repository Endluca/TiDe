## 分类说明

- `PRD/`：当前总 PRD、任务级 PRD 和历史页面 PRD。
- `接口与数据/`：当前共享任务表契约、数据库表结构和历史跨系统方案；以目录 README 的分类为准。
- `业务参考/`：上游总需求、运营补充、积分方案及业务对齐答复。
- `技术方案/`：后端架构、数据关系和模块归属设计。
- `后端开发准备/`：开工门槛、嘉荷检查清单、历史准备验收和当前公共后端开发验收；可执行资产位于根目录 `backend/`。
- `开发规划/`：阶段性开发计划；V2 前的旧规划已归档，不作为当前实现依据。
