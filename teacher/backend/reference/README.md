# 后端参考实现

## `teacher-faq-demo/`

- 来源：同事已经完成的 AI 问答代码，保留其独立 Git 仓库和原有文件结构。
- 用途：后续建设本系统 AI 问答能力时，用于梳理已有知识库、提示词、模型适配、问答接口和未命中问题收集能力，并在此基础上重新设计正式实现。
- 当前状态：正式 Canonical FAQ 已独立迁入 `../content/faq/`；运行与导入均不再依赖本参考仓库。
- 边界：它不是本项目的正式后端源码，不直接并入 `backend/src/`，也不在未与原作者协作确认时修改其代码或提交历史。
- 安全：其中的本地 `.env` 继续由父仓库忽略；任何密钥、连接信息和真实业务数据都不得复制进主仓库。

正式重构前，应先从该项目提炼能力清单和输入输出合同，再决定哪些逻辑复用、重写或淘汰。
