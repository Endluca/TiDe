# 新师训练营教师端｜世文共享数据库集成说明

## 已确定架构

- 两端使用同一个 PostgreSQL；教师端自有表放在 `tide` Schema。
- 共享任务表为 `public.task_templates` 和 `public.task_assignments`。
- 教师端积分总览固定读取 `public.teacher_scorecard_current`。
- 教师端逐课积分和课程事实固定读取 `public.teacher_lesson_score_current`。
- 浏览器不连接 PostgreSQL；后端每次查询都使用当前会话的 `teacher_id` 过滤。
- 不保留积分 HTTP 副本、原始表重算、评分配置读取、本地积分快照或其他回退路径。

## 数据归属

| 数据 | 来源 | 教师端行为 |
|---|---|---|
| 教师身份与基础资料 | `public.teachers` 或受限身份视图 | 注册校验与资料展示 |
| G01 TESOL 证据 | `public.teacher_source_wide.is_cpl_tesol` | 按 `tchr_id` 只读当前三值布尔事实；`NULL` 表示上游尚未提供。`is_self_introduce` 继续作为源表事实保留，但不进入教师端 G01。 |
| 教师积分总览 | `public.teacher_scorecard_current` | 按 `teacher_id` 读取一行并对白名单字段建模 |
| 逐课积分与课程事实 | `public.teacher_lesson_score_current` | 按 `teacher_id` 分页读取并对白名单字段建模 |
| G01–G09 模板 | `public.task_templates` | 只读已发布版本；隐藏 G00 不进入当前任务 |
| 教师任务实例 | `public.task_assignments` | 读取任务触发中心创建的 assignment，展示 G01–G09，只更新契约允许的状态字段 |
| 步骤、进度、答案、视频心跳、文件 | `tide.*` | 按 `task_assignment_id` 关联共享任务 |
| 外部消息 | `public.notifications / notification_events` | 可读；按契约幂等更新已读、点击和事件 |
| 原始积分与评分配置 | `score_entries / config_versions` | 教师端应用账号不读取、不写入；旧课程投影和旧逐维积分表已删除 |

世文触发中心全量创建 G 任务，并读取合法 `COMPLETED` 向内部积分表幂等结分。教师端只负责阶段开放和任务执行。

## 当前读取约束

- 总分、五维、组件、阈值、出营和金牌资格直接使用 `teacher_scorecard_current` 返回值，教师端不自行计算或推断。
- 基础分不是起始赠送分；它只由产能成长最高 10 分和必修任务最高 30 分的实际得分组成。
- “可获得积分”只由当前未完成且未进入终态的 G01–G09 及总览视图中的对应任务组件分值生成；隐藏 G00 不进入，合计为 0 时不返回该区块。
- 不定义或展示“待确认积分”。读取延迟只通过刷新或重试处理。
- 逐课只展示视图返回且 `awarded=true`、分值大于 0 的正向组件。
- 逐课课堂质量为 `SOURCE_MISSING` 或 0 分时不推断、不平均拆分。
- 后端只返回安全业务事实白名单；差评、拉黑、投诉、缺席原因和内部路由字段暂不进入教师端。

## `tit_teacher_crud` 最小权限

- `teacher_scorecard_current / teacher_lesson_score_current`：`SELECT`。
- `task_templates`：`SELECT`。
- `task_assignments`：`SELECT`；限定状态字段 `UPDATE`；不需要 `INSERT`。
- `teacher_source_wide`：只允许 `tchr_id / is_cpl_tesol` 两列 `SELECT`；禁止读取 `is_self_introduce`、整表读取和写入。
- `teacher_metric_snapshots`：已删除；G01 只读教师宽表两列。
- `notifications`：`SELECT`，以及 `status/read_at/clicked_at` 的 `UPDATE`。
- `notification_events`：`SELECT/INSERT`。
- `score_entries / config_versions`：无读取和写入权限；`lesson_facts / lesson_dimension_scores` 已删除。
- `tide` Schema：按教师端自有表契约授权。

本地授权脚本为 `database/scripts/grant-tit-teacher-crud.sql`。共享环境必须由表 Owner／DBA 执行；应用自身不提权。

## 状态与并发

- 新任务从 `ASSIGNED + row_version=1` 开始。
- 状态更新使用 `assignment_id + old row_version` 做乐观锁。
- 每次有效更新由数据库将 `row_version` 加 1，并写 `audit_events / outbox_events`。
- `COMPLETED / EXPIRED / WAIVED / CANCELLED` 不可再修改；`tit_teacher_crud` 不能主动写 `WAIVED / CANCELLED`。
- 纯步骤进度保存不修改共享任务状态或版本。
